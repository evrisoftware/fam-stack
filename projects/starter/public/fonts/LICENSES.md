# Font licenses

The fonts in this folder are redistributed under their own licenses, not the
project's MIT license. Each license's full text ships beside the fonts and is
deployed with them.

| File | Font | Copyright | License |
| --- | --- | --- | --- |
| `roboto.woff2` | Roboto (variable, latin subset) | 2011 The Roboto Project Authors | SIL Open Font License 1.1: [`roboto-OFL.txt`](roboto-OFL.txt) |
| `material-icons.woff2` | Material Icons (classic, full set) | 2018 Google, Inc. | Apache License 2.0: [`material-icons-LICENSE.txt`](material-icons-LICENSE.txt) |

Both can be re-downloaded from Google Fonts: Roboto from
<https://fonts.google.com/specimen/Roboto>, and Material Icons from
<https://fonts.googleapis.com/icon?family=Material+Icons> (request it with a desktop
Chrome user agent to be served the woff2). A replaced or added font ships its own
license text here.
